
=== Priv

The privileged tests exercise CSRs that are mandatory in each privilege mode.
They also test mandatory privileged instructions: `ecall`, `ebreak`, `mret`, and `sret`.
The CSR read/write/set/clear instructions themselves are tested in the
unprivileged Zicsr tests of <<Zicsr Control/Status Register Instructions>>.

`wfi` is tested in <<Interrupts>> and `sfence.vma` is tested in <<Sv* Virtual Memory>>.

Privileged tests do not test reserved or custom instructions or CSRs because their behavior is UNSPECIFIED.
Reserved instructions and CSRs are tested in the <<Ssstrict>> Ssstrict tests,
where they should throw an Illegal Instruction exception if not implemented.

==== Sm Machine-Mode CSRs and Instructions

These test CSRs and privileged instructions in machine mode.
The Sm suite also contains the Sm_F, Sm_V, and Sm_VF tests of the floating-point and vector CSRs and `mstatus.FS`/`mstatus.VS`, which run only when F, Zve32x, or Zve32f is also supported.

===== S_F Supervisor-Mode Floating-Point CSRs

These repeat the <<t-Sm_F-coverpoints,Sm_F>> tests from supervisor mode, using `sstatus.FS` in place of `mstatus.FS`.
They are the `S_F-NN.S` tests of the S suite and run when F is supported.
Their normative rules are listed in <<t-Sm-normative-rules>>.

include::{testplansdir}/priv/S_F.adoc[]

===== S_V Supervisor-Mode Vector CSRs

These repeat the <<t-Sm_V-coverpoints,Sm_V>> tests from supervisor mode, using `sstatus.VS` in place of `mstatus.VS`.
`misa` is not accessible in supervisor mode, so S_V omits `cp_misa_v_clear_set` and its VS=Off coverpoints are not crossed with `misa.V`.
They are the `S_V_*-NN.S` tests of the S suite and run when Zve32x is supported.
Their normative rules are listed in <<t-Sm-normative-rules>> and <<t-Vx-normative-rules>>.

include::{testplansdir}/priv/S_V.adoc[]

===== S_VF Supervisor-Mode Vector Floating-Point State

These repeat the <<t-Sm_VF-coverpoints,Sm_VF>> tests from supervisor mode, using `sstatus.FS` in place of `mstatus.FS`.
They are the `S_VF-NN.S` tests of the S suite and run when Zve32f is supported.
Their normative rules are listed in <<t-Vx-normative-rules>>.

include::{testplansdir}/priv/S_VF.adoc[]

==== U User-Mode CSRs and Instructions

These test additional CSRs that exist in user mode, and privileged instructions in user mode.
The U suite also contains the U_F, U_V, and U_VF tests, which repeat the Sm_F, Sm_V, and Sm_VF tests from user mode when F, Zve32x, or Zve32f is also supported, setting and reading `sstatus.FS` and `sstatus.VS` through T-SBI calls (`mstatus` when S-mode is not supported).

These test CSRs when the Zkr entropy extension is supported.  The seed CSR tests run once per
privilege mode: ZkrSm in M-mode, ZkrS in S-mode, and ZkrU in U-mode.
