
=== Zicntr

These privileged tests exercise counter and HPM reads (`time`, `cycle`, `instret`, `hpmcounter[31:3]`)
from lower privilege modes, as controlled by `mcounteren` and `scounteren`.
Note that the <<t-Zicntr-coverpoints, Zicntr>> and <<t-Zihpm-coverpoints, Zihpm>> unprivileged tests exercise access to these counters
from U-mode (or from M-mode when U-mode is not supported), and the <<t-Sm-coverpoints, Sm>> tests exercise access to `mcycle`, `minstret`, `mhpmcounter`, etc. from M-mode.

==== ZicntrPriv Counter Reads

The ZicntrPriv suite has one covergroup per privilege mode the tests run in: ZicntrPriv_Sm_cg (M-mode), ZicntrPriv_S_cg (S-mode) and ZicntrPriv_U_cg (U-mode).
The ZicntrPriv_Sm tests require Sm, so they are not part of a certificate without Sm, such as RVA23.
